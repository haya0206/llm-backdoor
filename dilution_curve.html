What this settles

At D2 the oracle probe is at 0.990, far above its 0.880 null — the information about the displaced package is entirely present in ΔW. The watchlist reads 0.870, just under the same null. So the failure between D0 and D2 is a search problem, not a loss of signal, and narrowing the candidate set is a live fix.

At D4 both probes fall below their own null (oracle 0.778 against a 0.823 null, best layer 0 — noise). That is the real floor: between 1% and 0.2% the signal genuinely goes. Meanwhile the attack still fires on 92% of the prompts where it has an install line to poison.

Correction to an earlier number

An earlier version of this curve reported D2 at 0.810 and concluded the probe could not be trusted below 1%. That used |z| as the score. The hypothesis is directional — a backdoored adapter aligns more with the displaced token — so taking the absolute value ranks a strongly anti-aligned benign adapter as if it were strongly aligned. D2 has 15 benign adapter-layers below z = −1.0, against 3 at D0. On identical data and layers, raw z gives 0.980 where |z| gave 0.810.
